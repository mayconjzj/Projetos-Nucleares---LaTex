# Projetos Nucleares — LaTeX

Repositório para organizar estudos, exercícios, trabalhos acadêmicos, artigos científicos e modelos em LaTeX.

## Estrutura

- `artigos/` — artigos científicos.
- `exercicios/` — listas, demonstrações e resoluções.
- `trabalhos/` — trabalhos de disciplinas e projetos acadêmicos.
- `estudos/` — investigações em andamento.
- `modelos/` — modelos reutilizáveis de documentos.

## Estudo em desenvolvimento

**Ações e fundos imobiliários no Brasil: acumulação patrimonial e geração potencial de renda**

Local: `estudos/comparacao-acoes-fiis/`

Arquivo principal: `main.tex`

A pasta contém também referências bibliográficas, um CSV para consolidação dos dados e documentação dos gráficos. A amostra atual é preliminar. Os resultados empíricos só serão preenchidos após auditoria das séries históricas, proventos, eventos corporativos e datas de negociação. Valores não verificados não serão apresentados como dados reais.

## Compilação

Para o estudo atual, use pdfLaTeX e Biber no Overleaf.
